My Projects

Here are some of my projects and assigment I have completed the first 2 years of my studies

Pyton Addition Quiz Project

In Introudction to Programming in first year first semester, I created a very simple 5 questions addition quiz using python. The program generates random math questions and checks the answers entered by the user

After the quiz was completed, the program calculates the user's final score and saves the results to a text file

Corporate Network Design Project

In introduction to Networking I in first year, first semester, I worked as part of a group to design and build a complete small corporate network based on a set of network requirements.

The project involved planning the network topology, configuring networking devices, assigning IP addresses, and testing communication between devices

Networking Case Study

In Introduction to Networking II in first year second semester, I completed a networking case study that required me to examine a network scenario and apply networking concepts to the situation.

The project helped me improve my understanding of network design, routing, troubleshooting, and how networking concepts can be applied to real world situations.

Python Inventory Management Program

For my Object-Oriented Programming course, I developed an inventory management program using Python. The program allows users to add, view, and update inventory items and save or load inventory data using a JSON file

This project demonstrated OOP concepts including classes, inheritance, method overriding, encapsualtion, file handling, and custom exceptions.

EIGRP Routing Lab

In Advanced Networking I in second year first semester, I completed a networking lab involving the configuration of EIGRP for IPv4 on multiple routers.

The lab involved configuration EIGRP, verifying learned routes, checking router connectivity, and troubleshooting routing problems.
